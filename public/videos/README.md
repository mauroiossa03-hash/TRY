Drop your looping ping-pong background footage here as `hero-loop.mp4`
(referenced by `HERO_VIDEO_URL` in `src/lib/config.ts`).

Recommended: 1920x1080+, H.264 mp4, under ~8MB, 10-20s loop, no audio track
needed (it's played muted). The hero falls back to the static image in
`public/images/` on mobile, on reduced-motion, or if this file is missing.
